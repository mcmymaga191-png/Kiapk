1. Создайте новый репозиторий на github.com.
2. Загрузите в него всё содержимое этой папки, включая скрытую папку .github.
3. Откройте вкладку Actions, дождитесь зелёной галочки (2-5 минут).
4. Откройте последний запуск, внизу в Artifacts скачайте who-paid-apk (ZIP с app-debug.apk).
5. Установите APK на телефон.
